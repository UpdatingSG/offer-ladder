# Offer Ladder — Journey Plan

Personal tracker for a **Backend SWE** offer cycle targeting top-pay India companies (~₹50L+ TC path).  
Current CTC: **₹22 LPA**. Target join-by: **Jun 2027**. First cold apps: **mid-Nov 2026** (after Diwali 8 Nov).

## Locked rules

| Rule | Choice |
|------|--------|
| Track | Backend SWE only (no ML deep dive) |
| Weekday focus | 45–60 min |
| Floor | Tiny required tasks; rest / 10–12h office days keep streak |
| Rest budget | Max **2** rest/tour days per week |
| Gym | **4×**/week + **2** walks (30–45 min) |
| Content (X / YouTube / Tharun / editing) | **Weekend only** 60–90 min review (automation runs parallel) |
| 100xDevs | **Paused** until applications sent &gt; 0 |
| Bike tours | Flexible; log as **Rest / tour** |

2. **Home · Pre-Diwali** (2 Oct – 8 Nov) — DSA 70% / Design 30%, body transform  
3. **Apply open** (9 Nov – 31 Dec) — cold apps from ~15 Nov; unlock courses after first app  
4. **Interview push** (Jan – Mar 2027) — mocks + real loops  
5. **Offer window** (Apr – Jun 2027) — close and join  

## Weekly rhythm (defaults in the app)

- **Mon / Tue / Thu:** DSA floor + gym  
- **Wed:** HLD block + walk  
- **Fri:** HLD drill *or* LLD rotation (alternating weeks) + walk  
- **Sat:** Gym + content review block  
- **Sun:** Flexible / tour = rest
